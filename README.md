# SFM plugin

Build a simulation model with a UI, step by step, in Claude Code or GitHub Copilot: **Level 1** uses the Simulation
Foundation Model (SFM) as it is, through its MCP server; **Level 2** makes the model your own project, which you can
change without limits, with the same model page as SFM. Design: `docs/SFM_Plugin_Design.md` in the SFM repository.

Tests (with an environment that has SFM installed): `python -m pytest -q tests`
